### Gaps Summary

One gap, narrow and reproducible. With a single TOC window, which is the normal case and the only case in an installed iPhone app, an update never reloads a game: the prompt shows only on the home, « Mon compte », « Mes amis » and the solo setup, and in a game « Réglages » only shows a line. With two TOC tabs or windows in one browser (a computer, or Chrome and the installed app on Android, which share one service worker), « Mettre à jour » pressed in one reloads a game running in the other, because the library's default reload runs in every tab. A solo game is not saved, so it is lost. An online table rebuilds after the reload, but it is still reloaded. The same happens to other tabs when the 4002 « Recharger la page » is used at a table. The fix is small: an `onNeedReload` in `startUpdates` that reloads only the tab that asked, or a tab where `canPromptUpdate` holds. A tab in a game keeps running, and the update applies there when it next reaches the home. Add a two-page PWA test.

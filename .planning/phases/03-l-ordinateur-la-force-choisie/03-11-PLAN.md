# Phase 3 Plan 11: Qui commence la donne

## Objective

Romain, 2026-10-17: « Il faut aussi savoir quel joueur va jouer le premier la donne actuelle ».
RULES.md R-03 / G9: the player after the dealer (clockwise) starts each of the three deals of a pack.
The game already shows the dealer (banner « On rebat les cartes. Donneur : X », the « D » disc on the
felt, the bar's « Donneur : X · Donne n sur 3 »), never the starter. Show it with the same means.
This is a proposal: 03-UI-SPEC.md marks it « à confirmer par Romain » with a dated note quoting him.

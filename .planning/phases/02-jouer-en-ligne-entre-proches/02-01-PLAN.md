# Phase 2 Plan 01: Traceur — deux navigateurs à la même table par son lien, chaque coup validé par le serveur

## Phase Goal

**As a** proche de Romain, **I want to** jouer la même partie de TOC avec trois autres, chacun sur son téléphone ou son ordinateur, sur une table dont le serveur fait autorité, **so that** on joue ensemble à distance, sans que personne puisse voir la main d'un autre, et qu'une coupure ou une pause ne fasse jamais perdre la partie.

(Mapped from the ROADMAP Phase 2 Goal and its five success criteria. The ROADMAP `**Goal**` line is not written in user-story form; run `/gsd-mvp-phase 2` to formalise it if wanted.)

## This Plan's Slice

After this plan two browsers open the same table link, each types a first name, takes a colour, the creator starts, the server deals, and a move played in one browser shows up in the other: the shared protocol, the pure table core, the Durable Object with its SQLite snapshot and alarm, the router, both deploy configs, the browser connection and the session seam, all in one slice. The later plans deepen it: 02-02 proves that no hand ever leaks and readies the deploy build, 02-03 gives the computer players their natural pace and the Champion its sliced search, 02-04 the home screen, 02-05 the waiting room and the invitation, 02-06 the pause, 02-07 the resume, 02-08 the quick messages, 02-09 the rematch and the game record, 02-10 the full checks, the deploy and Romain's acceptance tests.

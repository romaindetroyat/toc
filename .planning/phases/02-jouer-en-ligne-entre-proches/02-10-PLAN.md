# Phase 2 Plan 10: Vérification finale, une partie à quatre navigateurs, la mise en ligne et la recette de Romain

## Phase Goal

**As a** proche de Romain, **I want to** jouer la même partie de TOC avec trois autres, chacun sur son appareil, sur une table dont le serveur fait autorité, **so that** on joue ensemble à distance, sans triche possible, et qu'une coupure ne fasse jamais perdre la partie.

(Mapped from the ROADMAP Phase 2 Goal; see 02-01.)

## This Plan's Slice

The other plans each ran only the tests they touched. This plan runs everything once, plays a whole game between four browsers, creates the D1 database if the token allows it, publishes the game at https://toc.romaindetroyat.workers.dev, checks it there, and writes the acceptance tests Romain and his family will run on their phones, with every choice made for him that he still has to confirm.

Purpose: one place where Romain and the verifier find the proof, the live game and the questions of phase 2.
Output: green gates, quatre.spec.ts, tools/smoke-online.mjs, the deployed Worker, 02-UAT.md.
</objective>

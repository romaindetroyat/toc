# Phase 2 Plan 09: La fin de partie pour tous, la revanche, et la trace de chaque partie

## Phase Goal

**As a** proche de Romain, **I want to** jouer la même partie de TOC avec trois autres, chacun sur son appareil, sur une table dont le serveur fait autorité, **so that** on joue ensemble à distance, sans triche possible, et qu'une coupure ne fasse jamais perdre la partie.

(Mapped from the ROADMAP Phase 2 Goal; see 02-01.)

## This Plan's Slice

After this plan the end of an online game is announced to the four at once, each from their side, and « Revanche » starts a new game at the same table with the same seats once everyone agrees (D-08). Every finished game leaves one line in the D1 database for phase 5's history, written once whatever happens, and never blocking the game if D1 is not there yet (D-14).

<objective>
Add the finished state, the rematch votes and the rematch start to the core, the idempotent game record to D1 (migration, optional binding, retry by alarm), and the online end plank with its vote row.

Purpose: PLAY-07 (SC5 second part) and the game-end record that supports HIST-01 for phase 5.
Output: rematch.ts, record.ts (core and worker), the D1 migration, the online EndScreen, revanche.spec.ts.
</objective>

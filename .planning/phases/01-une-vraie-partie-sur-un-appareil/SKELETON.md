## Capability Proven End-to-End

A player taps « Jouer la partie » on the launch screen (`#/`), lands on the game screen (`#/partie`) showing Romain's original board assembled from its four quarters, taps the blue knight standing on the blue diamond, and watches it hop 4 cells clockwise while 4 synthesized hoof clops play on the `AudioContext` clock, both driven by the same `hopTimeline(4)` output.

Layers crossed by that one path: pnpm workspace → `packages/engine` (pure topology: colours, exits, ring walk, `pawnMoved` event) → `packages/board` (calibrated `layout.json`, `hopTimeline`) → `tools/` (board composite + calibration) → `apps/web` (hash router, Svelte 5 screens, SVG scene over the composite `<img>`) → Director (event queue) → Animator (WAAPI on inner `<g>`) + AudioEngine (Web Audio, unlocked inside the tap) → Playwright e2e on phone and desktop projects.

## Architectural Decisions

| Decision | Choice | Rationale |
|---|---|---|
| Framework | Svelte 5.57.2 SPA built by Vite 8.3.4 (`@sveltejs/vite-plugin-svelte` 7.3.1), ~30-line hash router (`#/`, `#/partie`, `#/sons`) | CLAUDE.md stack; no SSR needed; tiny runtime for phones; SvelteKit adds an adapter for nothing |
| Language | TypeScript **6.0.3** (deviation from CLAUDE.md's 7.0.2, inside its own "pin 5.9/6.x if a tool lags" fallback) | `svelte-check` 4.7.6 crashes on TS 7 (reproduced in RESEARCH Pitfall 1) |
| Rules engine | `packages/engine`: pure TypeScript, "just-in-time" package (`exports: { ".": "./src/index.ts" }`, no build), `lib: ["ES2022"]`, `types: []`, erasable syntax only, relative imports with explicit `.ts` extensions | Runs unchanged in the browser now, in a Durable Object in Phase 2, in bots in Phase 3, and directly under Node 22 (`node file.ts`, verified) for tools |
| Engine contract | `newGame`, `legalActions`, `apply(state, seat, action) -> { state, events }`, `viewFor(state, seat)`; events (`GameEvent` union) are the only input of rendering, animation and audio | Same contract becomes the Phase 2 network protocol (RULE-19) |
| Randomness | sfc32 PRNG state inside `GameState`; seed from `crypto.getRandomValues` in the shell only | Deterministic replay and tests; engine purity; CSPRNG seed meets RULE-02 in Phase 1 |
| Data layer | None server-side in Phase 1. Game state is in memory (JSON-safe). Persistence = browser `localStorage` (`toc.settings.v1`, `toc.soundnotes.v1`), every access in try/catch with in-memory fallback | Phase 1 is single-device; D1 + Durable Object SQLite arrive in Phase 2 |
| Auth | None in Phase 1 | Accounts and passkeys are Phase 4 |
| Board art | Build-time composite of the four quarters (`tools/build-board.mjs`, sharp) into `plateau-{640,1280,2560}.webp`, HTML `<img srcset>` under one `<svg viewBox="0 0 2560 2560">`; the art is never redrawn | FX-01; SVG `<image>` has no srcset |
| Cell geometry | `packages/board/layout.json` (normalised 0..1) generated by detection (`tools/calibrate-board/calibrate.mjs`), guarded by invariant tests | Re-measuring never touches rules code |
| Animation | Web Animations API on inner `<g>` groups (outer `<g transform>` = static anchor), feet at local (0,0), no SVG filters | Compositor-friendly; promise-based sequencing |
| Audio | Hand-rolled Web Audio; `AudioContext` created and resumed inside the « Jouer la partie » tap; clops scheduled with `AudioBufferSourceNode.start(t)` from `hopTimeline().clops`; synthesized sounds are the shipped baseline | FX-04 cadence lock; licence-clean |
| Debug surface | Debug-only features (`?debug=geometry`, `?scenario=`, `?etat=`, `?graine=`, `?vitesse=test`, `window.__tocDebug`) exist only when the compile-time constant `__TOC_DEBUG__` is true (dev server, or `VITE_TOC_DEBUG=1` at build time, which the e2e build sets); they are loaded by dynamic `import()` behind `if (DEBUG)`, so production builds drop them | Threat T-01-02 |
| Tests | Vitest 4.1.x (pinned `^4.1.11`, never 5.x), fast-check 4.10.2, Playwright 1.64.0 driving `/opt/pw-browsers/chromium-1194` (projects `phone` = iPhone 13 emulated, `desktop` = 1280×800) | Phase 2 workers pool needs Vitest 4; WebKit absent so iOS is a human check |
| Lint / format | Biome 2.5.15 on `.ts`/`.mjs`/`.json` only; `svelte-check` 4.7.6 gates `.svelte` | Biome reports false "unused" on Svelte templates (RESEARCH Pitfall 5) |
| Package manager | pnpm workspace, `packageManager: pnpm@10.34.7` (container ships 10.28.0, which also works) | CLAUDE.md; Vitest/Wrangler compatibility |
| Deployment | Local only in Phase 1: `pnpm --filter @toc/web dev` (dev) and `pnpm --filter @toc/web build && pnpm --filter @toc/web preview` (production build). Cloudflare Workers static assets arrive in Phase 2 | Phase 1 has no server |

## Subsequent Slice Plan

Each later phase adds one vertical slice on top of this skeleton without altering its architectural decisions:

- Phase 2: the same engine runs inside a `TableDO` Durable Object; clients send intents, receive `viewFor` + redacted events; four devices play one table.
- Phase 3: `packages/bots` gains levels 2 to 5 behind the same `legalActions`/`viewFor` contract.
- Phase 4: accounts (better-auth passkeys), friends, tables, solo launcher, PWA install and update prompt.
- Phase 5: history, stats, leaderboard, help, tutorial, accessibility audit.

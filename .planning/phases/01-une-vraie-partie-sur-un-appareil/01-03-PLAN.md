# Phase 1 Plan 03: Le contrat du moteur et les règles R-01 à R-08

## Phase Goal

**As a** joueur, **I want to** faire une partie complète de TOC contre trois joueurs gérés par l'ordinateur, sur le plateau original, avec des cavaliers animés et sonorisés, **so that** je retrouve une vraie partie de TOC fidèle aux règles maison validées par Romain, avec l'ambiance du plateau original.

## This Plan's Slice

After this plan Romain can read the first half of the house rules in French (teams, board, deals, exchange, turn, As/Roi, number cards, the 4), each with scenarios written as data, and the engine contract (types and event union) is fixed before any rule is coded. Plan 01-05 writes R-09 to R-16, the points to validate and the pictures; plan 01-07 is Romain's validation. The same scenario files become the engine's acceptance tests (plans 01-12, 01-13) and the debug scenario loader (plan 01-15).

Fixture layout (one file per group of rules, each exporting one typed `Scenario[]` per rule section): `scenarios/table.ts` (R-01 to R-05), `scenarios/cartes.ts` (R-06 to R-08), and in plan 01-05 `scenarios/valet-sept.ts` (R-09, R-10), `scenarios/prises-maison.ts` (R-11 to R-13), `scenarios/fin.ts` (R-14 to R-16).

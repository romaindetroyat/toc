# Phase 1 Plan 20: Les figures traditionnelles des cartes, licences vérifiées Summary

**The 12 Valets, Dames and Rois now show the traditional French figures of svg-cards 4.0.2 (LGPL-2.1) as separate SVG files cut out of its sprite sheet by `tools/import-card-art.mjs`, credited on the sheet « Crédits et licences », and a test fails when any bundled font, figure or sound has no licence row.**

- **Tasks:** 2 (Task 2 run as RED, then GREEN)
- **Files:** 6 modified, 3 created plus 14 generated asset files
- **Commits:** 3

## Accomplishments

- `tools/import-card-art.mjs` follows `assets/cartes/CHOIX.md`. For svg-cards it runs `npm pack svg-cards@4.0.2 --ignore-scripts` in a scratch directory outside the repo (nothing installed, no dependency added), checks the tarball against the registry integrity, refuses any install hook, extracts the 12 figures from `svg-cards-indented.svg` and copies `LICENSE` (as `LGPL-2.1.txt`) and `AUTHORS`. The Romain-files branch (webp via sharp, licence copy) is written but not exercised, since the option is svg-cards.
- Each figure is a standalone SVG with only the shared parts it needs; card background, frame, corner indices and big corner pips are left out because the card face draws its own corners (D-24) and the indices are text in a font the browser may lack. No `<script>`, `<text>`, `<image>` or external reference is left in any file (tested).
- `COURT_FIGURES` is filled from the files by a Vite glob (`?url`). The files are 52 to 81 kB (about 25 to 31 kB gzipped each) so Vite emits them as separate files in `dist/assets` and never inlines them, which keeps them replaceable as CHOIX.md requires. `Card.svelte` already rendered `COURT_FIGURES[card]` as an `<img>` (plan 01-16), so it needed no change; checked by screenshot on phone and desktop viewports that the figure sits between the two corners.
- `uncoveredAssets` plus tests (RED commit first): file name, path and directory prefix matching, licence texts exempt, no sibling-directory leak, new file without a row is listed.
- `LICENSES.md` has the `cartes` row (source, authors David Bellot, Huub de Beer and contributors, LGPL-2.1, modification note, repository URL); the credits sheet shows a Cartes group with the name « Figures des cartes (Valet, Dame, Roi) ».
